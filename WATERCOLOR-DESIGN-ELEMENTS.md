# Okim Dive - Watercolor Design Elements for Generation

This document contains detailed prompts for generating watercolor design elements to be used across the Okim Dive website. All elements should maintain a consistent watercolor aesthetic with soft edges, visible brush strokes, and a dreamy, underwater atmosphere.

## Global Style Guidelines

**Color Palette (from brand guide):**
- Ocean Mist: #A8DADC (soft blue-green)
- Deep Water: #457B9D (muted blue)
- Sand: #F1FAEE (warm off-white)
- Cloud: #FEFAE0 (very light warm white)
- Coral: #E63946 (warm coral - use sparingly for accents)
- Sunset: #F4A261 (warm orange - highlights)
- Kelp: #2A9D8F (teal green - secondary)

**Style Characteristics:**
- Soft, flowing watercolor washes
- Visible brush strokes and texture
- Gentle gradients and color bleeding
- Organic, natural shapes
- Transparent and layered effects
- White space integration for breathing room

## USAGE NOTES

1. **All elements should have transparent backgrounds** unless specified as full-page backgrounds
2. **Maintain consistent watercolor style** across all elements - soft edges, visible brush strokes, color bleeding
3. **Color consistency** - stick to the defined palette, variations should be subtle
4. **Size flexibility** - elements can be scaled but maintain aspect ratio where noted
5. **Layering** - many elements are designed to be layered over backgrounds and photos
6. **Subtlety** - decorative elements should enhance, not overwhelm content
7. **White space** - allow breathing room, watercolor works best with space

## IMPLEMENTATION GUIDE

After generating these elements:
1. Save all as PNG with transparent backgrounds (except full backgrounds)
2. Optimize file sizes for web (use tools like TinyPNG)
3. Organize in folder structure: `/assets/watercolor/`
   - `/backgrounds/` - full page backgrounds
   - `/hero-banners/` - page hero banners
   - `/decorative/` - marine life, plants, etc.
   - `/frames/` - card and photo frames
   - `/dividers/` - section dividers
   - `/icons/` - course icons, social backgrounds
   - `/corners/` - corner decorations
   - `/overlays/` - texture overlays
4. I will then integrate these into the website HTML/CSS
5. Test responsiveness across different screen sizes
6. Adjust opacity and positioning as needed
